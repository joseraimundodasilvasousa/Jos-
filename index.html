Sobre Este Projeto

Este é um exemplo prático de uma página web construída com HTML5 e CSS3. Ele é totalmente responsivo, o que significa que se adapta muito bem tanto na tela do seu computador quanto no seu celular.

Você pode usar este modelo como ponto de partida para criar o seu portfólio, a página do seu negócio ou o seu blog pessoal. Sinta-se livre para mudar as cores, os textos e as imagens!
